# Kids Coding Hub — Python Missions
**منصة تحديات تفاعلية لتثبيت حصص Python Future Builders — Level 1**
---
## الهدف من المنصة
**Kids Coding Hub — Python Missions** منصة تعليمية تفاعلية مصممة لطلاب المرحلة الثانوية (15–18 سنة) الذين يبدأون رحلتهم مع البرمجة بلغة Python. بدلًا من أن يقتصر التعلم على دروس نظرية أو نسخ كود جاهز، تقدم المنصة تجربة تفاعلية قائمة على التحديات القصيرة:
- **توقع الناتج** قبل تشغيل الكود.
- **تحليل الأخطاء** وإصلاحها خطوة بخطوة.
- **بناء مشاريع صغيرة** بمعايير نجاح واضحة.
- **مواجهة Boss Challenge** نهائي لمراجعة كل حصة.
- **استلام تقرير نهائي** يلخّص الإنجاز والنقاط التي تحتاج مراجعة.
المنصة تطبق منهجية **PRIMM** (Predict — Run — Investigate — Modify — Make) في كل حصة، وتعتمد على **محاكاة آمنة** للكود داخل المتصفح دون الحاجة إلى تنفيذ Python حقيقي أو إرسال الكود لخوادم خارجية.
---
## المحتوى التعليمي
المنصة تضم **6 حصص** تغطي أساسيات Python:
| الحصة | العنوان | المفاهيم الرئيسية |
|---|---|---|
| 01 | Welcome to Python | Program، Algorithm، Interpreter، `print()` |
| 02 | Input, Variables & Types | `input()`، Variables، `str/int/float/bool`، Casting |
| 03 | Numbers & Operators | العمليات الحسابية `+ - * / // % **`، Precedence |
| 04 | Strings That Talk | Concatenation، Repetition، Escape Sequences، f-strings |
| 05 | True or False | Boolean، Comparisons، `and/or/not` |
| 06 | Making Decisions | `if/else`، Indentation، النقطتان `:` |
كل حصة تحتوي على:
- **12 مهمة تفاعلية** بأنواع متنوعة (اختيار من متعدد، توقع، تصحيح أخطاء، ترتيب، مطابقة، بناء كود...).
- **مشروع صغير** ينطبق على ما تعلمه الطالب.
- **Boss Challenge** من 5 جولات.
- **تقرير Mission Report نهائي**.
- **شارة إنجاز** خاصة بالحصة.

## مميزات المنصة
- ✅ **واجهة عربية RTL** بالكامل، مع صناديق كود LTR منفصلة.
- ✅ **لا تسجيل دخول مطلوب**: التقدم يُحفظ محليًا في `localStorage`.
- ✅ **XP / جواهر / قلوب**: نظام تحفيز مستقل لكل حصة.
- ✅ **فتح تدريجي**: المهمة التالية تفتح بعد إكمال السابقة.
- ✅ **Feedback مفصّل**: يجيب دائمًا على "ماذا حدث؟" و"لماذا؟" و"ما الخطوة التالية؟".
- ✅ **محاكاة آمنة**: الكود لا يُنفذ خارجيًا ولا يُستخدم `eval()`.
- ✅ **متوافقة مع الموبايل والتابلت واللابتوب**.
- ✅ **Dark mode** كوضع افتراضي.
